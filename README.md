# Lunar-Lander-v3-PPO

[![Gymnasium](https://shields.io)](https://farama.org)
[![PyTorch](https://shields.io)](https://pytorch.org)
[![License: CC0-1.0](https://shields.io)](https://creativecommons.org)

Проект демонстрирует применение алгоритма **PPO (Proximal Policy Optimization)** для решения классической задачи обучения с подкреплением — посадки лунного модуля в окружении **LunarLander-v3** (библиотека Gymnasium). 

В репозиторий включены скрипты для самостоятельного обучения модели, тестирования обученного агента, а также готовые веса нейросети, достигающие высокой точности.

---

## Результаты и Метрики

* **Окружение:** `LunarLander-v3`
* **Алгоритм:** Proximal Policy Optimization (PPO)
* **Целевая метрика:** Средняя награда за последние 100 эпизодов — **`mean(100) ~ 280+ очков`**.

---

## Структура Репозитория

* `Lesson 1.py` — Скрипт для сборки архитектуры нейросети и полноценного **процесса обучения** (сохраняет логи и лучшую модель).
* `LL test.py` — Скрипт для **демонстрации и тестирования** обученного агента в визуальном режиме (загружает сохраненные веса).
* `lunar_lander_ppo.pth` — Готовый скомпилированный тензор (веса обученной нейросети), показавший результат ~280 очков.

##  Инструкция по использованию

###  Тестирование
Если вы хотите сразу посмотреть, как обученный лунный модуль совершает идеальную посадку, используйте готовый файл весов:

```bash
python "LL test.py"
```
*   Скрипт инициализирует окружение в режиме `render_mode="human"`.
*   Загружает веса из файла `lunar_lander_ppo.pth`.
*   Выводит графическое окно симуляции, где можно наблюдать за действиями агента в реальном времени.
*   > **Важно!** - Загружаемый тензор весов должен иметь название  `lunar_lander_ppo.pth` и находится в одном корне со скриптом.

###  Запуск собственного обучения
Если вы хотите переобучить нейросеть с нуля или изменить гиперпараметры:

1. Откройте и запустите скрипт обучения:
   ```bash
   python "Lesson 1.py"
   ```
2. В процессе обучения модель будет периодически оценивать свою эффективность. 
3. При достижении максимального счёта прогресс автоматически перезапишет веса в файл `lunar_lander_ppo.pth`.

##  Описание Архитектуры и Логики Кода

Проект реализован на связке **PyTorch** и **Gymnasium**. Логика работы алгоритма делится на две ключевые сети (Архитектура Actor-Critic):

| Компонент | Роль в алгоритме PPO |
| :--- | :--- |
| **Actor (Актёр)** | Анализирует вектор состояния корабля (8 параметров: координаты, скорости, угол, контакт ног с землей) и выбирает оптимальное действие (включить левый/правый/главный двигатель или бездействовать). |
| **Critic (Критик)** | Оценивает, насколько хороша текущая позиция модуля, предсказывая ожидаемую долгосрочную награду. Используется для вычисления функции преимущества (Advantage). |

* Функция потерь ограничивается с помощью `clip_param` (обычно \(0.1\)–\(0.2\)), что не позволяет обновлять стратегию слишком резко и сохраняет стабильность обучения.
* Оптимизатор: **Adam**.
